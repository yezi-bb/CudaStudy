## 一、基础概念：OCT 二维切片 & 3D 容积逻辑

### 1. OCT 成像基础

临床 / 工业 OCT 采集模式：

1. **A-scan（A 线）**：单点深度方向一维信号（z 轴）；

2. B-scan（B 扫 / 二维切片）   （目前OCT扫描，按照imagespcing排列）

   ：横向扫描多条 A-scan，构成 

   2D 灰度切面 (Height × Depth)

   - `x`：横向扫描方向
   - `z`：光学深度方向（组织纵深）

3. **C-scan（容积扫描）**：步进移动探头，连续采集**多张平行 B-scan 二维切片**，沿**Y 轴**堆叠。

> 坐标系约定（行业通用，贴合你后续 CUDA 三维处理）
>
> - 单张 B-scan 二维切片：`width(X) × depth(Z)`
> - 堆叠方向：**Y 轴（切片序号方向）**
> - 最终三维容积尺寸：`[W, Y_slices, D]` 或者内存布局 `[Y, D, W]`（重点区分内存排布！）

### 2. 堆叠逻辑通俗理解

- 每一张 B-scan = 一层断层图像；
- 依次把第 0 张、第 1 张、第 2 张…… 第 N 张 B 扫**沿着 Y 方向紧密叠放**；
- 所有切片尺寸必须完全一致：相同宽度 W、相同深度 D；
- 堆叠完成 → **3D Voxel（体素）容积数据 Volume Data**。

```
Bscan_0  (W × D)
Bscan_1  (W × D)
Bscan_2  (W × D)
......
Bscan_M-1(W × D)
↓沿Y轴堆叠
Volume[Y, D, W]   Y ∈ [0, M-1]
```

### 3. 体素 (Voxel) 概念

2D 图像最小单元 = 像素 (Pixel)

3D 容积最小单元 = 体素 (Voxel)，包含三维坐标 `(x,y,z)`，存储灰度值（uint8 /float32 OCT 原始信号）

## 二、内存排布关键（极易踩坑，重点预习）

> 所有 CPU/CUDA 数组**一维扁平化存储**，三维坐标 → 一维索引换算公式。

### 设定参数

- `W`：单张 B-scan 宽度（X 轴）

- `D`：单张 B-scan 深度（Z 轴）

- ```
  Ycnt
  ```

  ：B-scan 切片总数（Y 轴）

  三维容积尺寸：

  ```
  Ycnt × D × W
  ```

#### 排布方案（推荐采用【Y 优先】，贴合 OCT 采集顺序）

内存顺序：先存完整一张 B 扫，再存下一张 B 扫

三维坐标 `(y, z, x)`

一维线性索引公式：

\(idx = y \cdot (D\cdot W) + z\cdot W + x\)

- y：第几张切片
- z：深度方向
- x：横向坐标

> ❌ 反面坑：不要混用 `(x,y,z)` 顺序！索引写错，切片完全错乱，图像错位翻转。

## 三、业务需求定义

输入：

1. 一组 OCT 二维 B 扫灰度图像（多张`unsigned char*`二维图像缓存）
2. 每张图像固定：宽度 W，深度 D
3. 切片总数量 Ycnt

输出：

CPU 端连续一维数组 `unsigned char* volume`，扁平化存储三维容积，可直接后续传给 CUDA 做 3D 滤波、3D 阈值、体渲染。
