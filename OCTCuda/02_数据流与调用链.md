# 02 — 数据流与调用链

本文把 AIOCT 中 CUDA 相关路径收成四张逻辑链，供每周对照。路径均为仓库内相对路径。

---

## 链 A — 实时 Scan 成像（最高频）

```text
采集线程 / DMA 缓冲 (U16 或 Vivo U8)
        │
        ▼
GpuHandlingDataThreadController   (is_need_gpu_processing)
        │
        ▼
ImageProcessingController
        │
        ├─ VGPU_Data_Resampling_For_Scan[_Vivo](..., is_device_to_host=false)
        ├─ VGPU_Get_FFT_Power_Interpolation_Result(..., false)
        ├─ VGPU_Get_Current_Frame_FFT_data  (可选存盘)
        ├─ VGPU_Transpose(..., false)
        ├─ VGPU_CheckCatheterBreakDetection / VGPU_Catheter_AutoCalibration  (条件触发)
        ├─ VGPU_DSC(..., INTER_BILINEAR, false)
        ├─ VGPU_Image_Enhancement(..., false)
        └─ VGPU_Gray2Color(..., true)  → cv::Mat → UI
```

**学习要点**

- 中间阶段尽量 `false`，最后伪彩再上屏。  
- `DOC_SCAN` 与缓冲尺寸在 `VGPU_Allocate_Parameter_Manager` 已定。  
- 校准失败/折断会改 cut 或弹状态，但不改变「FFT→DSC」主干。

**精读文件**

- `Source/Controllers/AlgorithmControllers/ImageProcessingController.cpp`（Resampling 起约 500+ 行一带）  
- `Source/Controllers/ThreadManagementControllers/GpuHandlingDataThreadController.cpp`

## 链 B — 回拉 Pullback 批处理

```text
回拉结束，Host 持有多帧 Raw
        │
        ▼
VGPU_Check_pullback_Data_memory
VGPU_Set_Original_pullback_Data_To_GPU(frame_sum, noise, gain, offset, U16*, U8*)
        │
        ▼
VGPU_Handle_All_Preview_data / 逐帧 VGPU_Pullback_ProcessData_ToImage
        │
        ▼
VGPU_Get_All_FFT_data  → 分析用 U16 FFT 卷
        │
        ▼
VGPU_Handle_All_FFT_data / VGPU_Handle_All_Calibration_Image
        → rectangle + circle 体数据 → 存盘 / 预览 / DICOM
```

**学习要点**

- 整卷上传一次，避免 550× 小拷贝。  
- 分析侧可 `VGPU_Set_all_FFT_data_to_Gpu` 再算连续校准 / IPA。

## 链 C — 分析 / 导入导出 / 竞品

```text
导入 .oct / DCM / 旧记录
        │
        ├─ VGPU_Get_old_data_* / Denoising_data_toLog / U16↔F32
        ├─ VGPU_PullbackRawData_To_* / C7C8_* / PullbackDcm_*
        └─ VGPU_OneFrameRawData_To_Image / Hnad_One_Frame_Data
                │
                ▼
        IntegrationChannel / ImportationExportationController
```

**学习要点：** 同一套 DSC/增强，入口数据格式不同（Raw / FFT / DCM）。

## 链 D — IPA（斑块衰减）

```text
GetGlobalFFTData()  (U16 FFT 卷)
        │
IPAAlgorithmController::IPAProcessing
        │  填充 att_paras (P60/P80/C7 分支)
        │  reshaped_lumen / labels_data 自 DicomModel
        │
        ▼
VGPU_Calculate_Ipa_Result(att_paras, fft_u16, lumen, media=100, labels,
                          miu_gray_array, line_ipa_miu, lipid_threshold, noise, isVivo)
        │
        ├─ miu_gray_array  ──► VGPU_All_Aline_Mu_Data_To_Image ──► IPA 圆图序列
        └─ line_ipa_miu    ──► 存入 m_pre_ipa_analysed_result
                                    │
                                    ▼ 用户改阈值 / 模式
                         VGPU_UpdateValueIPA(...)
                                    │
                                    ▼
                         IPA_L / IPA_A / IPA_T / colorbars → UI (BackgroundIPA / IPAZone)
```

**旧对照链（08Code）**

```text
GUP_SetIpaalgorithmConfig → GPU_Calculate_Ipa_Result → (现已并入 VGPU_*)
```

**精读文件**

- `Source/View/ViewSource/Analysis/IPAAlgorithmController.cpp`  
- `BackgroundIPAUpdateThreadController.cpp`  
- `IPAZoneController.cpp`  
- `08Code/Algorithm/Analysis/include/IpaAlgorithmKernel.cuh`

## 显存与错误旁路（横切）

```text
任意重计算前: VGPU_GetCurrentGPUMemory / Check_pullback_Data_memory
计算中异常:   VGPU_GetCudaErrorStatus → UI 可关机保护
DL 之后:     VGPU_Reallocate_memory
严重故障:     VGPU_ResetCudaMemory → 再 Allocate
```

---

## 开源仓应对齐的最小状态机

```text
Idle → Allocated → StreamingFrame → (optional) PullbackBulk → AnalysisLoaded → IpaComputed → Freed
```

每状态只允许文档中列出的 API 子集；Week13 任务会要求你实现该状态机。
