## 2. 物理模型（公开表述，教学级）
OCT 轴向信号强度随深度按**单散射近似**衰减：
```
I(z) = I0 · exp(-μ·z) · (G(z) 束腰/几何调制)
⇒ ln I(z) = ln I0 − μ·z + ln G(z)
```
- μ（mm⁻¹）：组织光衰减系数——反映组织成分（脂质/纤维/钙化散射吸收特性）。
- 血管内 OCT 中，**脂质斑块区域 μ 显著偏高** → “衰减”特征成为斑块易损性分析输入之一（临床称 intraplaque attenuation）。
- 同一条 A-line 上，管腔（血液冲洗后低信号）→ 管壁内膜/中膜 → 外膜/斑块的 μ 变化正是 IPA 要量化的曲线。

## 3. 为什么需要 GPU
- 卷 = frames(≈550)×theta(≈500)×depth(≈1025) ≈ **2.8 亿 A-line 深度样本**；
- 每 A-line 需做“Lumen 边界外、分段滑窗拟合 μ(z)” → 天然数据并行；
- 交互上要求“用户改脂质阈值 → 秒级重算毯展/色图”（W12 的 UpdateValueIPA）。

## 4. 源码里的物理量（真实：att_paras，VGPU_Process.cuh L161-178）
| 字段 | 公开物理解释 |
| --- | --- |
| z0 | 衰减曲线沿深度的起点偏移（源移/介质） |
| zR / zC / zw | 光束/窗参数：瑞利长度、中心、窗宽（几何调制 G(z)） |
| SNRmax / noise_level | 噪声门限：低于此不参与拟合 |
| minwin / step_success / step_fail | 拟合窗最小点数与成功/失败时的窗步进 |
| scandepth | 有效成像深度范围 |
| number_theta/depth/alines/frames | 卷尺寸（角度线 × 深度 × 帧） |

## 5. 一句话总结（面试口径）
“IPA 是把回拉卷中每条 A-line 的 log 强度沿深度做窗式拟合，估计每个位置的组织衰减系数 μ，脂质斑块区 μ 高 → 输出 μ 体数据，再渲染成灰度/伪彩圆图与线级统计供临床判读。”
