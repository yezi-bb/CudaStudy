# 一、邻域运算（图像滤波底层基础）

## 1. 核心定义

**邻域运算**：对图像每个像素 `(x,y)`，不取单像素单独计算，而是取它周边一小块矩形窗口（邻域 / 卷积核窗口）内所有像素共同参与运算，输出新像素值。

单像素阈值属于**点运算**（只看自身灰度）；滤波、边缘检测、形态学全是**邻域运算**。

### 关键概念

1. **中心像素**：当前待计算输出的像素 `I(x,y)`
2. **邻域窗口（Kernel / 卷积核）**：常用尺寸 `3×3`、`5×5`，OCT 医疗影像优先 3×3（兼顾速度与降噪）
3. **步长 stride**：常规滤波步长 = 1，窗口逐像素滑动覆盖全图
4. **边界填充**：图像最边缘像素邻域超出原图，需补像素（复制边缘 / 零填充 / 镜像，OCT 用复制边缘避免黑边伪影）

### 通用计算流程（3×3 窗口举例）

1. 窗口滑动到像素 `(px,py)`，取出周围 3×3 共 9 个像素；
2. 按滤波规则对 9 个像素做数学运算（均值、高斯加权、取中位数）；
3. 运算结果作为新图像 `Out(px,py)` 的灰度；
4. 窗口右移 / 下移，遍历整张 OCT 图所有像素。

### 邻域运算 CUDA 映射适配

二维线程 `(px,py)` 对应中心像素；每个线程读取窗口 9 个相邻全局像素，完成加权求和，天然适合 GPU 并行。

# 二、图像滤波完整原理（OCT 前置降噪核心）

滤波本质：**邻域加权统计，平滑抑制噪声，保留有效病灶结构**，是阈值分割前必备预处理。

分为两大类：线性滤波、非线性滤波。

## 2.1 线性滤波（像素加权求和）

输出 = 邻域像素 × 对应核权重 累加

### （1）均值滤波（简单平均）

3×3 均值核：

原理：邻域 9 个像素取平均值，随机散斑噪声互相抵消。

优缺点：降噪强，但病灶边缘、分层结构会模糊，OCT 少单独使用。

### （2）高斯滤波（OCT 首选线性平滑）

权重服从二维高斯分布：窗口中心像素权重最高，越远离中心权重越低。

优势：

1. 平滑噪声同时最大程度保留视网膜分层、病灶边缘；
2. 加权天然贴合 OCT 灰度渐变组织，无生硬模糊；
3. GPU 可分离卷积加速（横向、纵向两次一维卷积，速度翻倍）。

## 2.2 非线性滤波（不做加权求和，基于像素排序统计）

### 中值滤波（OCT 散斑噪声最优）

流程：

1. 取出 3×3 邻域 9 个灰度值；

2. 从小到大排序，取中间第 5 个数作为输出像素；

   降噪逻辑：OCT 散斑噪点是孤立极值（极亮 / 极黑点），排序后中位数会直接剔除极值，完美消除椒盐类散斑噪声。

   优势：

   不模糊病灶边缘，是医疗断层影像标配预处理。

## 2.3 滤波通用作用（适配你 OCT 病灶分割流水线）

1. 消除散斑噪声，避免阈值分割生成大量虚假小白点病灶；
2. 平滑灰度突变，均衡断层明暗，提升 Otsu 阈值分割稳定性；
3. 抑制微小纹理干扰，粗分割后连通域轮廓更完整；
4. 前置滤波 → 阈值二值化 → 形态学优化，标准医疗图像预处理链路。

# 三、OCT 光学相干断层图像噪声完整来源分析

OCT 噪声统称**散斑噪声 (Speckle Noise)**，是相干成像设备固有噪声，分为 5 类来源：

## 3.1 相干散斑噪声（最主要、占 90% 干扰）

### 产生原理

OCT 使用**低相干激光**作为光源，激光具备强相干性：

不同视网膜组织层反射的反射光，在探测器处发生**相干干涉**；反射光相位随机叠加、相消干涉，形成随机明暗颗粒状噪点。

### 图像表现

整张断层图布满米粒大小黑白颗粒，灰度剧烈跳变；直接阈值分割会产生大量孤立虚假病灶。

## 3.2 探测器电子噪声

1. **暗电流噪声**：探测器无入射光时自身电子热运动产生随机灰度波动；

2. 读出噪声：采集像素信号时电路放大引入的高斯随机噪声；

   影响：图像整体基底灰度波动，导致全局阈值 T 不稳定，批量 OCT 分割效果忽好忽坏。

## 3.3 组织微观结构散射噪声

视网膜细胞、纤维、微血管微观尺度小于激光波长，光线发生随机散射；

同一层正常组织内部灰度剧烈起伏，分层边界模糊，病灶与正常组织灰度重叠。

## 3.4 运动伪影噪声（临床采集动态噪声）

患者眼球轻微抖动、呼吸颤动，断层扫描过程中组织位置偏移；

表现：图像横向条纹、分层错位，产生长条状明暗伪影，干扰病灶粗分割。

## 3.5 系统光路噪声

1. 光路镜片灰尘、散射；

2. 光源功率不稳定，帧与帧之间整体亮度漂移；

3. 耦合光纤振动带来信号衰减；

   表现：整张图像局部明暗斑块，Otsu 自动阈值计算偏移，分割漏检 / 过分割病灶。

# 四、噪声对阈值分割的负面影响（贴合你现有代码业务）

1. 孤立噪点灰度极值，二值化后生成大量微小白色虚假病灶连通域；
2. 组织灰度剧烈波动，类间方差计算失真，Otsu 自动阈值不准；
3. 病灶边缘被噪声割裂，二值掩码碎片化，无法提取完整病灶 ROI；
4. 批量扫描图像亮度不一致，固定阈值完全失效，必须依赖滤波 + 自适应 Otsu。

# 五、配套工程落地方案（CUDA 流水线适配）

## OCT 标准降噪预处理流程

原始 OCT 灰度图 → GPU 3×3 中值滤波（消除散斑极值噪点） → GPU 高斯平滑（均衡灰度、保留边缘） → Otsu 自适应阈值分割 → 病灶二值掩码

## CUDA 邻域滤波实现要点

1. 3×3 窗口每个线程读取 9 个相邻像素，利用共享内存缓存邻域像素，减少全局显存重复读取，大幅提速；
2. 边界采用镜像填充，避免断层上下边缘产生黑色无效像素；
3. 滤波核与阈值分割核共用一套二维`dim3(32,32)`线程网格，复用线程调度逻辑，代码统一。
