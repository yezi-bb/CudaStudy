# 一、图像阈值分割基础原理

## 1. 核心定义

阈值分割是**基于像素灰度值的像素级二分类算法**：设定一个灰度阈值T，将图像所有像素划分为两类：前景（病灶 / 目标）、背景（正常组织 / 空白）。

通用数学表达式：

Ibin(x,y)={255,0,I(x,y)>T(高灰度目标，病灶亮区)I(x,y)≤T(背景暗区)

反向阈值（病灶偏暗时，OCT 常用）：

Ibin(x,y)={255,0,I(x,y)<T(病灶暗区)I(x,y)≥T(背景亮组织)

## 2. 算法本质

- 输入：单通道灰度图像（OCT 原始图本身是灰度断层图）
- 输出：二值图像（仅 0 纯黑、255 纯白，无中间灰度）
- 优势：计算极简、GPU 并行友好、速度极快，适合**病灶粗分割**（快速框选病灶区域，不做精细边缘）
- 局限：仅靠全局灰度，对光照不均、组织灰度重叠场景分割粗糙，仅作为粗提取前置步骤。

## 3. 常用阈值选取方案

### （1）固定阈值（OCT 粗分割首选）

人工根据 OCT 图像灰度范围固定T，工程最简单；

OCT 断层图像灰度区间稳定，同设备扫描图像灰度分布差异小，固定阈值足够完成粗分割。

### （2）Otsu 自适应阈值（自动全局阈值）

遍历所有可能T，最大化**前景 / 背景类间方差**，自动计算最优分割阈值；

适合批量 OCT 图像灰度波动大、无法固定阈值的场景，GPU 可并行实现直方图统计。

### （3）局部自适应阈值（病灶和背景灰度混杂时）

分块计算局部阈值，抗光照不均；OCT 一般仅全局阈值即可满足粗分割需求。

# 二、医疗 OCT 影像特点 & 二值化分割逻辑

## 1. OCT 影像灰度分布特征（光学相干断层扫描）

1. 分层结构：视网膜 / 血管 / 病灶为薄层组织，灰度偏暗 / 偏亮；玻璃体空白背景灰度均匀；
2. 病灶特征：水肿、渗出、裂孔区域灰度和正常视网膜存在明显差值；
3. 噪声：散斑噪声，二值化后会产生孤立小白点 / 小黑洞；
4. 数据形式：二维断层灰度图，单通道，适合二维 CUDA 线程映射处理。

## 2. OCT 病灶粗分割业务逻辑（完整流水线）

### 步骤 1：图像预处理（降噪，阈值分割前置）

OCT 存在散斑噪声，直接阈值会出现大量噪点：

- 简单方案：3×3 均值滤波 / 高斯滤波（GPU 二维卷积并行）平滑图像；
- 目的：消除孤立噪点，避免分割后产生大量虚假病灶区域。

### 步骤 2：灰度阈值二值化（核心粗分割）

根据病灶灰度特性选择阈值规则，分两种临床场景：

#### 场景 A：病灶区域灰度低于正常组织（视网膜裂孔、积液暗区）

像素灰度小于阈值T判定为病灶，输出白色前景：

cpp

运行

```
// CUDA核函数核心逻辑
unsigned char pix = d_oct[py * width + px];
if (pix < T)
    bin_out[idx] = 255; // 病灶标记白色
else
    bin_out[idx] = 0;   // 背景黑色
```

#### 场景 B：病灶区域灰度高于正常组织（渗出、疤痕亮斑）

像素灰度大于阈值T判定为病灶：

cpp

运行

```
if (pix > T)
    bin_out[idx] = 255;
else
    bin_out[idx] = 0;
```

### 步骤 3：形态学后处理（剔除噪点，优化分割轮廓）

二值图存在细碎噪点，粗分割必须加开 / 闭运算：

1. **腐蚀（Erode）**：消除孤立小白噪点，缩小病灶轮廓；

2. 膨胀（Dilate）

   ：填补病灶内部微小黑洞，恢复病灶尺寸；

   

   组合「先腐蚀后膨胀」= 开运算，完美去除 OCT 散斑噪声带来的虚假病灶。

### 步骤 4：粗分割结果输出

1. 二值掩码图：白色区域为候选病灶区域；
2. 外接矩形计算：统计白色像素连通域，框选病灶 ROI，供后续精细分割 / 测量。

## 3. 为什么阈值分割适合 OCT「粗分割」

1. 计算量极小，CUDA 二维线程单像素并行，百万像素图像毫秒级处理；
2. 无需标注训练，无深度学习部署成本，设备端轻量化运行；
3. 仅用于快速定位病灶大致位置，不要求精准边缘，完美匹配粗分割定位需求；
4. 可作为 AI 精细分割、病灶厚度测量、面积计算的前置预处理步骤。

# 三、适配 CUDA 二维线程的 OCT 二值化完整核函数 Demo

基于之前讲的`dim3`二维网格 / 块映射，单线程处理单个 OCT 像素：

cpp

运行

```
#include "cuda_runtime.h"
#include "device_launch_parameters.h"

// OCT图像固定阈值二值化核函数
// T：分割阈值，病灶暗区 < T 输出255白色掩码
__global__ void OctThresholdKernel(
    const unsigned char* d_octIn,  // 输入OCT灰度图
    unsigned char* d_binOut,       // 输出二值掩码
    int width, int height,
    unsigned char T)
{
    // 二维像素坐标映射
    unsigned int px = blockIdx.x * blockDim.x + threadIdx.x;
    unsigned int py = blockIdx.y * blockDim.y + threadIdx.y;
    // 边界保护，防止图像越界
    if (px >= width || py >= height)
        return;
    // 一维展平数组下标（行优先存储）
    unsigned int idx = py * width + px;
    unsigned char gray = d_octIn[idx];

    // OCT病灶暗分割逻辑：灰度低于阈值=病灶前景
    if (gray < T)
        d_binOut[idx] = 255;
    else
        d_binOut[idx] = 0;
}

// 主机调用逻辑
void RunOctBinSeg(unsigned char* h_oct, int w, int h, unsigned char threshold)
{
    size_t imgSize = w * h * sizeof(unsigned char);
    unsigned char *d_in, *d_bin;
    // 显存分配、数据上传省略...

    // 二维线程配置：32×32 Block，对齐Warp，单块最大1024线程
    dim3 block(32, 32);
    dim3 grid(
        (w + block.x - 1) / block.x,
        (h + block.y - 1) / block.y
    );
    // 启动二维网格核函数
    OctThresholdKernel<<<grid, block>>>(d_in, d_bin, w, h, threshold);
    cudaDeviceSynchronize();

    // 掩码图下载回CPU，后续形态学处理、连通域分析
    cudaMemcpy(h_binResult, d_bin, imgSize, cudaMemcpyDeviceToHost);
}
```

# 四、临床 OCT 分割关键注意事项

1. **灰度归一化**：不同设备扫描 OCT 亮度不一致，预处理统一灰度区间 (0~255)，保证阈值稳定；
2. **散斑噪声抑制**：阈值前必须平滑，否则分割出大量伪病灶；
3. **阈值动态调整**：不同眼底疾病病灶灰度不同，水肿用低阈值，渗出用高阈值；
4. **粗分割定位边界**：阈值仅获取病灶大致区域，如需精准轮廓，需搭配边缘检测、深度学习模型；
5. **显存访存优化**：二维图像行优先存储，线程按 x 横向遍历，满足合并访存，大幅提升 CUDA 计算速度。

# 五、整体流程总结（OCT 病灶粗分割流水线）

OCT 原始灰度图 → GPU 高斯降噪平滑 → 全局阈值二值化 → 形态学开运算去噪 → 病灶二值掩码 → 连通域提取 ROI 病灶区域。
